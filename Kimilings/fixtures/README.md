# Contract fixtures

router_plan.jsonl is a fictional routing decision, used only to exercise the CLI. Its claimed LDT candidate list is deliberately not independently verified. The router therefore ignores it for hard gating and returns a TRM-ranked plan.

Official ARC puzzles, Kimi model weights, real activation captures, synthetic VPD training data, and paid-hosted evaluation receipts belong outside the repository. Tests create tiny artificial ARC JSON files in temporary directories.
