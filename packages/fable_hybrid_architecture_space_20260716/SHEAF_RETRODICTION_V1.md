# Controller-Mesh Sheaf Retrodiction v1

This post-package sidecar tests whether spectral invariants of the sealed controller interfaces retrodict
oversight leverage. It does not modify the frozen Fable ZIP.

The registered analysis covers 60 arm-seed policy instances and retains the source benchmark's 31 behavioral
equivalence classes. Nine classes alias multiple architecture signatures, so behavioral equality is not treated
as sheaf equality.

Primary result: spectral gap correlates negatively with utility delta (`rho=-0.723`) and low-band rank correlates
positively (`rho=+0.678`); both exceed 128 topology/rank/spectrum-preserving transport nulls (`p=0.0078`). In this
mesh, useful fallback intervention creates structured low modes. The naive claim that a larger gap always means a
more stable or useful controller is false without typed residuals.

The preregistered kernel-migration prediction fails. No seed's exposed-direction capture loss exceeds matched
random directions. A post-hoc signed-margin audit instead finds that all three proposers translate across the
frozen gate. Seed 29 has the largest translation while remaining the independent-audit counterexample. Exposed
passage, kernel migration, and hidden-audit evasion are distinct mechanisms.

Receipts and full math are in `reports/checkpoint_controller_mesh_sheaf_retrodiction_v1.md` and
`docs/controller_mesh_sheaf_retrodiction.md`. Independent external audit is pending.
