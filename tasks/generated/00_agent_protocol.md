# Agent Protocol

Operate in small, inspectable steps.

1. Read `README.md`, `docs/hybrid_architecture.md`, and the current workorder.
2. Run the quickstart commands.
3. Modify at most three files per pass.
4. Write a short `handoff.md` containing: files changed, commands run, observed failures, next action.
5. Stop at any checkpoint labeled STOP.

Do not invent citations. Mark missing citations as `CITE_NEEDED`. Do not claim VPD editing exists. Say `VPD-instrumented` or `VPD-guided` unless a concrete feedback mechanism is implemented.
