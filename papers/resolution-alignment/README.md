## Retrieval and experiment protocol

Run `python papers/resolution-alignment/fetch_pdfs.py --list` to list arXiv candidates, or `--fetch` to download only the linked arXiv papers into the ignored `pdfs/` directory. Treat fetched PDFs as local personal research copies and respect publisher/arXiv licensing. For an actual reproducible scientific claim, use the protocols in [`docs/causal_receipt_recurrence_proposal.md`](../../docs/causal_receipt_recurrence_proposal.md) and [`docs/silico_sft_vpd_protocol.md`](../../docs/silico_sft_vpd_protocol.md).
