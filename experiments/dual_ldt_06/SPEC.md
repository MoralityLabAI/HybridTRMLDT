# Dual-LDT-06 mathematical specification

The Beast certifies three-step open-loop programs from a fixed grammar. Its host-owned state records policy time, resource credits, installed guards and progress. Every positive-probability successor of every primitive must remain in the recoverable modes active/maintenance. A current-policy violation, insufficient resources, unavailable guard or isolated successor rejects the whole plan. The same host transition semantics are used by a forward integer-mass evaluator and a recursive rational checker. Agreement checks the calculation; it does not validate the model against external reality.

The Jinn has explicit outcome preferences theta. A project pays its four-dimensional feature vector only when it first completes. Completing another designated project earlier unlocks a bonus. Consequently rewards depend on the execution order and observed project progress. Expected return is U_theta(P)=E[sum_t theta dot feature_reward_t - resource_cost_t], with gamma=1 and horizon three. New theta vectors are authored experimental objectives rather than reconstructions of the old lane-head personas.

The mathematical recursion for a fixed remaining program is V(s,a::P)=-cost(a)+sum_(s',p,f) p*(theta dot f+V(s',P)). Empty tail has value zero. The Beast separately requires every branch to be authorized and recoverable. Probability is a utility weight, never permission to discard a low-probability unsafe branch.

For each project, the probability of completion cannot exceed the binomial probability of enough successes in the number of scheduled work operations. Giving every completion its maximum prerequisite bonus, ignoring chronology and resource/guard restrictions, gives a sound upper bound for all feasible plans. The code represents the upper and actual utility as integer numerators with denominator 64. Its exact arithmetic tests cover all candidates in the development sanity-check subset; report processing checks the bound on every feasible plan too.

A learned student supplies ranking only. Every admitted incumbent is checked by independent rational replay; evaluated infeasibility is also checked. At budget k, L_k is the best checked feasible utility and B_k is max(L_k, upper(a) for unchecked a). Then L_k <= U* <= B_k. Search records actual regret and certified bound gap separately. The hindsight exhaustive oracle is used only in assertions/scoring and is never used to rank or stop a candidate search.

Conditional learned-value theorem: if |U(a)-Uhat(a)|<=epsilon on a common feasible domain, an argmax of Uhat on that domain has regret <=2epsilon against its true optimal program. Lean proves the integer-scaled two-error inequality and finite-path invariant. This premise is not supplied by training MAE, and it does not by itself describe budget-limited search that still has unverified candidates.

Exact exhaustive symbolic evaluation over all 343 plans is the oracle. The registered comparison also includes a stronger symbolic order based on the sound relaxation. Neural students share the same parameter count at one/four latent passes, matching the repository's shared-GRU design pattern. They are newly trained weights with different inputs and outcomes from the old TRM checkpoints. Three seeds and final-step checkpoints are fixed before validation/report. No tuned recipe is selected after inspecting results.

Search timings include full candidate-input construction, prediction, sorting, every issuer evaluation, the independent checker, and the bound computation. Training cost and model loading are recorded separately. Timings are one CPU-session measurement, not a hardware-general speed claim. Each method first verifies the same zero-return idle fallback. The whole finite grammar is evaluated to retain fixed-budget measurements even after an earlier exact certificate; the first certificate time in query units is recorded.

This is a synthetic finite-horizon open-loop study. The exact oracle is optimal only within the same declared grammar. Adaptive policies could outperform it. All semantic meanings, oversight mechanisms, outcome features and objective weights remain assumptions controlled by the experiment.

Primary precedents: Alshiekh et al., Safe Reinforcement Learning via Shielding (AAAI 2018), https://doi.org/10.1609/aaai.v32i1.11797 ; Yonetani et al., Path Planning using Neural A* Search (ICML 2021), https://proceedings.mlr.press/v139/yonetani21a.html . This experiment does not claim novelty for shielding, Bellman recursion or learned search guidance.
