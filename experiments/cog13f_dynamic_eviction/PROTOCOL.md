# COG-13F protocol (before execution)

COG-13E found that a static future-set marginal-value ridge learner lost to recent reuse density on deeper traces. This follow-up estimates dynamic eviction regret under a fixed continuation policy. No COG-13E result is used for fitting or selecting the new model. Native Lean measurements are still pending, so this is an explicitly synthetic development pilot.

New seed 2026112619, 64 training, 24 calibration, 32 ordinary and 32 deeper roots. Train/calibration/ordinary branch lengths 4–10, deeper 11–16; 60 requests/root. Keep exact old/new generated-world fingerprint disjointness. Four public request regimes, three persistent modeled byte caps (128/256/512). Fixed request tapes, positive command costs, rejection cost, open-only admission, longest exact cached prefix, candidate temporarily over budget. All arms use identical input trace.

At an overbudget eviction decision C, for each candidate i, force eviction of i, finish any remaining eviction using COG-13E recent density, then simulate the next 12 requests under recent density. The dynamic label is J_i, total future modeled suffix/failure work. Regret r_i = J_i - min_j J_j. Train root-balanced ridge (0.2 penalty) to predict the within-decision centered residual of log(1+r_i/10) relative to the centered analytic prior log(1+100*recent_density). Inputs: COG-13E's 13 causal features plus coverage-adjusted recent density, relative candidate bytes, capacity, and overflow ratio. Labels depend on future requests and are training-only; the future-aware oracle is a separately named diagnostic. No training on calibration or evaluation. Collect from recent-density and coverage-adjusted recent-density behavior at each cap; all candidate counterfactual rollouts are charged offline. A within-decision shuffled regret control uses the same fitting pipeline.

Calibration: choose one global lambda from [0,0.25,0.5,1] minimizing aggregate calibration work plus one unit/ranked candidate, two units/learned feature evaluation, one unit/coverage evaluation, 0.01 units/byte transferred. Tie-break smaller lambda. Zero is an admissible result and skips learned feature calculation. Do not change the design after readout. Evaluate LRU, work density, recent density, coverage density, fixed residual lambda=1, calibrated residual, shuffled residual lambda=1, and future-aware dynamic oracle. Report raw work and synthetic overhead-adjusted work, transfer and ranking counters, per-root pairings, descriptive bootstrap intervals. Primary development criterion: calibrated residual must improve overhead-adjusted aggregate deeper work over both recent and coverage density; fixed residual must outperform matched shuffled labels on deeper traces before further learned claims. No scientific confirmation or hardware claims.

Audit must independently replay path/cost/admission/eviction/cap accounting, reproduce nonoracle score choices, retain every root and reject forged cost, score, cache and missing request. Verify that dynamic label rollouts use only the registered continuation policy and report all offline costs. Export train-only examples and source/receipt hashes. Native follow-up requires green COG-13D and measured per-command CPU and retained memory costs.
