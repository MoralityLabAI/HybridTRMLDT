# COG-13 — portfolio scheduling and resumable verified proof ledgers

## Motivation

[Cogentic](https://arxiv.org/abs/2609.40324) motivates research agents that reuse verified intermediate results. This pilot adds a resource-allocation layer to the common COG-02 Horn proof environment. It distinguishes the budget spent choosing a root from the capacity to retain its intermediate facts.

Sources:
- [DataGoblin COG-02 #77](https://github.com/MoralityLabAI/DataGoblin/pull/77), source commit ae0dbecffc1d246778ee47d8f3d8ec59b5948f2b.
- [LoopedTransformers COG-03 #394](https://github.com/MoralityLabAI/LoopedTransformers/pull/394), exact compressed task snapshot at c1c903b3f0664ee19838fcba45bd67e24f779aab.

The imported corpus contains 256 public synthetic Horn worlds, 64 per split. No Cogentic proof trace is represented. The compressed and decompressed SHA-256 pins, task digests, root uniqueness and exact cohort sizes are checked before any training or evaluation.

## Experiment

Each consecutive eight-root portfolio receives 48, 96 or 144 total verifier calls (prefix readouts of one run). A deterministic local router applies a ready rule with priority for a conclusion within two backward goal hops, breaking ties by published rule order. All original facts, public rules, and the goal are visible.

Schedulers:
- round robin with 8, 4, 2 or 1 resident ledger slots;
- static smallest rule count;
- smallest remaining rule count;
- smallest remaining full goal-ancestor count (privileged symbolic baseline);
- learned remaining cost (nine-feature ridge regressor, 64 training roots, each root weighted equally, ridge 0.01);
- full symbolic ancestry scheduler AND full-ancestry router (different router, separate baseline);
- offline shortest-remaining exact cost for the fixed local router (clairvoyant diagnostic, never a deployable policy).

The learned features are public rule/atom counts, number of established facts beyond initial facts, unknown rule counts, ready rule count, missing goal premises, and missing atoms within two backward hops, with fixed scaling. Split, family, root identity, future outcomes and the full symbolic closure are absent from learned features. Labels are residual verifier calls from full local-router training trajectories; no tuning on calibration or evaluation. Training consumes 723 selected rule checks. Offline diagnostic trajectories consume another 2,737 checks separately.

Cache model: store a map of root IDs to proved-fact sets; LRU eviction discards the set and retains only the immutable action tape. Resuming a cold root starts from its initial facts and replays each previous rule application, charging one call for every replay. The portfolio stops exactly at its budget or once all eight roots are complete. A partial restoration consumes its calls even if no new fact is produced. Static input graphs and action tapes are retained independently of this cache. Peak JSON-serialized ledger bytes include root IDs, and peak JSON tape bytes are reported separately. These byte counts are proxy serialization sizes, not measured process RSS.

The array-based replay checker reconstructs cache state, validates eviction order and tape prefixes, rechecks fresh and replayed premises, and checks cohort, cost, terminal status, cache/tape byte counts and budget-prefix readouts. It rejects a deliberately forged fact. It does not independently audit scheduling-policy selection. These are exact finite Horn checks, not native Lean compilation.

## Executed results

The core JavaScript functions were executed on the source-pinned snapshot in a sandbox with an independent gzip/SHA-256 decoder. The committed Node CLI uses native gzip/SHA-256; CI exercises the published entry point. 240 runs, 26,968 charged evaluation calls independently replayed. 64 roots per readout partition (eight portfolios), one deterministic fitted regressor. Full receipts can be generated by the CLI; only the summary is checked in.

At 144 calls on deeper portfolios, the local-router learned schedule and static size each finish 49/64, one below the local-router offline ceiling (50/64). Full symbolic routing finishes 64/64 with 962 selected verifier calls across the portfolios, below the allowed 1,152. Learned allocation has not established an advantage over static size.

Under deliberately fine-grained round robin, 1–4 cached ledgers cause 800 of 1,152 deeper calls to be spent restoring known derivations (69.44%). All three arms finish zero roots. With eight cached ledgers, replays disappear and 25 roots finish. The maximum serialized live-ledger sizes are 104, 205, 401 and 941 bytes respectively. Tape sizes are reported separately in results.json. Static-size scheduling uses at most 185 serialized live-ledger bytes in the deeper split, with zero replay under an eight-slot cap. A one-slot static-size run is a proposed control, not an executed result.

## Reproduce

Node 20+; no external npm dependencies.

```bash
curl -fL https://raw.githubusercontent.com/MoralityLabAI/LoopedTransformers/c1c903b3f0664ee19838fcba45bd67e24f779aab/research/cog03_ledger_router/data/tasks.jsonl.gz -o /tmp/cog13-tasks.jsonl.gz
node experiments/cog13_proof_budget/benchmark.mjs /tmp/cog13-tasks.jsonl.gz /tmp/cog13-run.json
```

Use a new output path. Output includes the full independently checked event logs, prefix and terminal results. The checked-in results.json contains the corresponding aggregate and source pins.

## Scope and next gate

Public engineering development evidence only. No confirmatory cohort, independent trained seeds, statistical superiority, actual neural LDT, TRM training, or native Lean run is claimed. The selected-step verifier counter excludes candidate applicability screening, feature scans, sorting, symbolic closure construction, CPU time and graph memory. In Horn worlds the public readiness predicate is as strong as the local premise checker; this cost separation is artificial. The full-closure baseline is useful precisely because the graph is available in advance. The two-hop router still has access to complete public rule syntax. The cache experiment deliberately imposes round-robin interference and is not evidence that physical RAM alone improves reasoning. Root weighting during fit does not establish evaluation independence; report portfolios as the scheduling unit.

For COG-13B, preregister comparisons using cache-aware scheduling (one-slot block scheduling and variable quantum, checkpoint-aware replacement, byte-matched partial ledgers), count proposal/feature/graph operations and measure wall time/RSS. Then import actual Lean obligations with expensive checkers and typed resumable proof snapshots. Use new independent roots, include matched static and symbolic controls and log every proposal and checker cost. A learned LDT route policy should use only public state and predict residual checker cost with calibrated uncertainty. Retain completion-first and fairness/long-root metrics so maximizing short-run throughput cannot quietly abandon hard problems.
